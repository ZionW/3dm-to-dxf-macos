# 3DM → DXF for macOS

**Language / 語言:** [繁體中文](README.zh-TW.md) · [English](README.en.md)

Drag `.3dm` files onto the macOS app to create `.dxf` files without opening Rhino.

將 `.3dm` 檔案拖到 macOS App 圖示，即可在不開啟 Rhino 的情況下產生 `.dxf`。

## Download / 下載

Download `3DM-to-DXF-macOS-arm64-v0.9.zip` from [Releases](../../releases/latest). Unzip it, then drag one or more `.3dm` files onto `3DM to DXF.app`.

從 [Releases](../../releases/latest) 下載 `3DM-to-DXF-macOS-arm64-v0.9.zip` 並解壓縮，再把一個或多個 `.3dm` 拖到 `3DM to DXF.app`。

This repository publishes the packaged app and usage documentation. It does not contain source code.

本儲存庫提供打包後的 App 與使用說明，不包含原始碼。
